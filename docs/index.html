Built for large music libraries

  • M4A, MP3, FLAC, WAV, AAC, OGG, Opus, AIFF, WMA, and APE.
  • Dates and formats checked before duration metadata is read.
  • Persistent SQLite cache and adjustable concurrent readers.
  • Defaults: modified in seven days, 25–35 seconds inclusive.

Load it on Unraid

Copy the current image to your appdata share, then run:

docker load -i /mnt/user/appdata/nas-audio-finder-v2.0.0-amd64.tar

Install the release's Unraid template, map your local music folder to /music and appdata to /config, then open port 8099. No image build is required.
